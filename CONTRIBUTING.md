# Contributing to the Diabetes Project

Thank you for your interest in contributing.

## How to Contribute

1. Fork the repository and create a feature branch.
2. Keep changes focused and clearly scoped.
3. Update documentation when behavior or setup changes.
4. Open a pull request with a clear summary of:
   - What changed
   - Why it changed
   - How it was validated

## Development Guidelines

- Prefer reproducible notebook runs (restart runtime and run all cells).
- Keep model and preprocessing updates traceable in notebook cells.
- Avoid committing generated datasets, model artifacts, or runtime outputs.

## Pull Request Checklist

- [ ] Notebook runs without errors in Colab/Jupyter
- [ ] README reflects any setup or usage changes
- [ ] No sensitive data or credentials are committed
- [ ] Changes are minimal and relevant to the issue

## Code of Conduct

By participating, you agree to collaborate respectfully and constructively.
