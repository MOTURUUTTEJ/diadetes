# Contributing to diadetes

Thanks for your interest in improving this project.

## How to contribute
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feat/short-description
   ```
3. Make focused changes.
4. Validate notebook execution for the cells you changed.
5. Commit using clear messages.
6. Open a Pull Request with a concise summary.

## Contribution guidelines
- Keep changes scoped and easy to review.
- Update `README.md` when behavior or setup instructions change.
- Do not commit secrets or personal credentials.
- Keep notebooks clean (remove unnecessary outputs if very large).

## Pull request checklist
- [ ] Changes are relevant and minimal.
- [ ] Notebook cells run without obvious errors.
- [ ] Documentation is updated when needed.
- [ ] No sensitive information is included.
